What the profile says

Attention is launch-bound. Its host range is 15.3x longer than its correlated CUDA work.
Linear projections amplify dispatch cost. 169 projection calls per batch account for 1.93 ms CPU per request-forward.
Sampling is not the bottleneck. Top-k, multinomial, and sampling softmax are all below 0.09 ms CPU each.

Method and interpretation notes
  • Decode steps 1-2 were excluded because real request shapes triggered Triton autotuning.
  • Steps 3-10 were stable batch-6 forwards: 8 batches and 48 request-forwards.
  • Displayed time is total measured time divided by 48 request-forwards. It is throughput cost, not batch-1 latency.
  • CPU values for ATen rows use the operator range. Triton rows use correlated cudaLaunchKernel host duration.
  • GPU values are kernels, memcpy, and memset correlated to each operation.
  • PyTorch operator ranges can be nested, so rows must not be summed into an end-to-end total.
